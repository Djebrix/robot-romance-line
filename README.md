[Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
bounty on make.fun.

## The line

> I must be a prompt, because you keep completing me.

## How it works

`main.py` (Python 3, standard library only, no network, no randomness)
writes the line deterministically to `/output/entry.txt`. Two runs produce
byte-identical output.
